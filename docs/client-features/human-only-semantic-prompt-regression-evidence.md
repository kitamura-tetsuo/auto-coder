# Human-only semantic prompt-regression evidence

Semantic prompt-regression Actions executions are classified by verified
repository workflow-path provenance and excluded from PR admission, waiting,
merge, deployment approval, and automatic repair decisions. Their generated
reports are non-actionable only when an exact versioned identity from
`github-actions[bot]` is verified against the represented workflow run and PR;
copied markers, unresolved provenance, ordinary CI, and human instructions keep
their normal authority. The active selective evaluator publishes immutable,
per-attempt human reports through trusted default-branch reporting code, while
deterministic prompt tests continue to run and fail normally in PR Tests.
